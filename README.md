# 江湖行旅

一款以原創武林世界為背景的繁體中文文字武俠回合制遊戲。玩家以自己的名字踏入江湖，選擇門派、習得武學，並在歷練中逐步成長。遊戲加入原創 SVG 場景插畫與人物互動：向師傅請教時會先走進演武場，下山後能在青石鎮和說書人、小販與客棧掌櫃互動，再選擇是否前往官道歷練。

## 開始遊玩

在瀏覽器開啟 [index.html](index.html) 即可遊玩，無需安裝或建置工具。

## 遊戲內容

- 輸入自己的江湖名，從五個門派與無門無派的道路中選擇起點。
- 透過門派演武領悟招式，累積閱歷提升境界與能力。
- 在江湖歷練中進行回合制戰鬥，使用攻擊、守勢、療傷或脫身策略。
- 在客棧休養恢復氣血與真氣，並管理行程中的風險。
- 進度自動保存在目前瀏覽器的本機儲存空間。

遊戲採用原創門派、角色與文本，借鑑傳統武俠的門派修習、江湖歷練與回合戰鬥玩法。
